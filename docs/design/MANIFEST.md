## 5. Fonts (woff2 + fonts.css)

Figma only provides font names, no files. All families used in the design are
freely available via Google Fonts (SIL Open Font License 1.1) — there is
**no** commercial font in the file. The subsets `latin` and `latin-ext` were
downloaded. Google serves Inter, Open Sans and Mulish as variable fonts: one
file per subset covers all weights, hence the `*-var-*` file names.

| File | Family | Weights in the design | Size |
|---|---|---|---|
| `fonts/inter-var-latin.woff2` | Inter | 400, 500, 600, 700 | 47 KB |
| `fonts/inter-var-latin-ext.woff2` | Inter | 400, 500, 600, 700 | 83 KB |
| `fonts/open-sans-var-latin.woff2` | Open Sans | 400, 600, 700 | 47 KB |
| `fonts/open-sans-var-latin-ext.woff2` | Open Sans | 400, 600, 700 | 34 KB |
| `fonts/poppins-400-latin.woff2` | Poppins | 400 | 8 KB |
| `fonts/poppins-400-latin-ext.woff2` | Poppins | 400 | 6 KB |
| `fonts/mulish-var-latin.woff2` | Mulish | 500, 700 | 29 KB |
| `fonts/mulish-var-latin-ext.woff2` | Mulish | 500, 700 | 26 KB |
| `fonts/fonts.css` | all | @font-face incl. `unicode-range` | 5 KB |

**Removed from the repo:** Poppins and Mulish are not used by a single piece
of text in the implemented UI. The four woff2 files and their `@font-face`
blocks in `fonts/fonts.css` have been removed and remain reachable through
the git history. The table still lists what the extraction produced.

**Not downloaded:** `Patrick Hand` and `Figtree` appear exclusively in canvas
annotations and in the design team's notes, in no UI element. `Figtree`
additionally appears in the file thumbnail on page `TN`.
