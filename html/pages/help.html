Was ist der PFG Issue Collector?

Der PFG Issue Collector ist ein Kanban-basiertes Projektmanagement-Tool, das eine Gruppe engagierter Studierender im Rahmen ihres Webentwicklungs-Bootcamps an der Developer Akademie entworfen und entwickelt hat.

Kanban, ein japanischer Begriff für „Anzeigetafel“, ist eine sehr wirksame Methode, um Arbeit sichtbar zu machen, laufende Arbeit zu begrenzen und die Effizienz (den Arbeitsfluss) zu maximieren. Der PFG Issue Collector nutzt die Kanban-Prinzipien, um Sie bei der Verwaltung von Aufgaben und Projekten in einer intuitiven, visuellen Oberfläche zu unterstützen.

Hinweis: Der PFG Issue Collector ist als Lernprojekt angelegt und nicht für einen umfangreichen geschäftlichen Einsatz vorgesehen. Wir bemühen uns um eine bestmögliche Nutzererfahrung, können jedoch keine durchgängige Verfügbarkeit, Zuverlässigkeit, Richtigkeit oder sonstige Qualitätsmerkmale garantieren.

So verwenden Sie das Tool

Die folgende Schritt-für-Schritt-Anleitung erklärt die Nutzung des PFG Issue Collector:

  1. Das Board erkunden
    Nach der Anmeldung finden Sie ein Standard-Board mit vier Listen: „Zu erledigen“, „In Bearbeitung“, „Warten auf Feedback“ und „Erledigt“. Zum Board.
  2. Kontakte anlegen
    Fügen Sie Kontakte hinzu, um zusammenzuarbeiten. Öffnen Sie Kontakte, klicken Sie auf „Neuen Kontakt hinzufügen“ und füllen Sie die erforderlichen Angaben aus. Kontakte können Aufgaben zugewiesen werden.
  3. Karten hinzufügen
    Karten sind Aufgaben. Erstellen Sie diese über Aufgabe hinzufügen oder über die „+“-Schaltflächen auf dem Board. Ergänzen Sie Titel, Beschreibung, Fälligkeitsdatum, Priorität, Kategorie, zugewiesene Personen und Unteraufgaben.
  4. Karten verschieben
    Verschieben Sie Aufgaben mit dem Arbeitsfortschritt zwischen den Spalten (z. B. „Zu erledigen“ → „In Bearbeitung“ → „Warten auf Feedback“ → „Erledigt“). So bleibt Ihr Arbeitsablauf transparent.
  5. Die Übersicht nutzen
    Die Übersicht zeigt die wichtigsten Kennzahlen (Aufgaben je Status, dringende Aufgaben, nächste Frist). Nutzen Sie sie als kompaktes Dashboard.
